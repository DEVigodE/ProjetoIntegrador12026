- **Desenvolvimento Web**: Aplicação completa full-stack

## 🛠️ Stack Tecnológica

**Backend:**

- Java + Spring Boot
- Spring Cloud (Eureka, Gateway, Config Server)
- Apache Kafka / RabbitMQ
- WebSocket + STOMP
- Keycloak (Identity and Access Management)
- Docker + Kubernetes

**Frontend:**

- React 18+
- TypeScript
- Material-UI / Ant Design
- WebSocket Client
- Redux / Zustand
